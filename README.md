# StockanneRR OBD2 Scanner

Aplicativo Android para leitura básica via adaptador ELM327 Bluetooth.

## Funções

- Leitura de RPM
- Leitura de velocidade
- Temperatura do motor
- Voltagem
- Códigos DTC
- Conexão com dispositivos Bluetooth pareados

## Compatibilidade

O funcionamento depende do veículo, do adaptador ELM327 e dos sensores disponíveis na ECU.

## Aviso

Este aplicativo está em desenvolvimento. Use como ferramenta auxiliar, não como diagnóstico profissional definitivo.
