# Política de Privacidade

Esta política de privacidade descreve como o aplicativo **StockanneRR - Obd2 Car Scanner** gerencia, coleta e utiliza as informações dos usuários.

## 1. Coleta de Dados e Permissões Sensíveis

Para oferecer suas funcionalidades principais, o aplicativo requer acesso a recursos sensíveis do dispositivo:

* **Dados de Localização (GPS):** O aplicativo coleta dados de localização precisa ou aproximada para permitir [explicar brevemente o motivo, ex: rastrear rotas / encontrar dispositivos próximos / registrar atividades]. Esses dados são processados localmente no dispositivo e [não são compartilhados com terceiros / são enviados para nossos servidores apenas para funcionamento do serviço].
* **Conectividade Bluetooth:** O aplicativo solicita permissão de Bluetooth e localização (exigida pelo sistema operacional para varredura de redes) para se conectar, sincronizar e interagir com dispositivos de hardware externos compatíveis.

## 2. Uso de Dados e Compartilhamento
Garantimos que os dados coletados pelas permissões de GPS e Bluetooth são utilizados estritamente para o funcionamento das ferramentas internas do app. Não comercializamos, transferimos ou compartilhamos dados de localização de nossos usuários com fins publicitários ou empresas de análise de dados de terceiros.

## 3. Serviços de Terceiros (SDKs)
O aplicativo pode integrar serviços de terceiros que coletam informações de forma independente para fins operacionais. Você pode revisar as políticas deles nos links abaixo:
* [Google Play Services](https://google.com)
* [Firebase Analytics & Crashlytics](https://google.com)

## 4. Retenção e Exclusão de Dados
Os dados de localização temporários são descartados assim que a sessão de uso ou a conexão Bluetooth é encerrada. Se o aplicativo armazenar qualquer histórico de dados em servidores, o usuário poderá solicitar a exclusão definitiva de suas informações a qualquer momento entrando em contato pelo e-mail de suporte.

## 5. Segurança
Implementamos medidas técnicas e administrativas comercialmente aceitáveis para proteger os dados coletados. Contudo, nenhum método de transmissão ou armazenamento eletrônico na internet é 100% seguro.

## 6. Privacidade de Crianças
Este aplicativo não é direcionado a menores de 13 anos e não coleta intencionalmente dados de identificação pessoal de crianças.

## 7. Alterações a Esta Política
Reservamo-nos o direito de atualizar esta política periodicamente. Recomendamos a revisão desta página para verificar modificações. As alterações entram em vigor imediatamente após a publicação.
